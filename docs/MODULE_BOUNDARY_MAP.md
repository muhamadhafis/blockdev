# Module Boundary Map

## Batasan Modul & Tanggung Jawab
- `app/`: Routing halaman dan metadata root layout.
- `components/ui/`: Komponen UI atomik dasar (Button, Badge, Cards, Animation primitives).
- `components/`: Komponen section halaman komposit (Hero, Navbar, Bento, Audience, Events, CTA, Footer).
- `lib/`: Helper utilities (`cn()` via `clsx` dan `tailwind-merge`).
- `public/`: Aset statis gambar dan video.
