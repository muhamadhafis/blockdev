# Glossary

Daftar istilah dan definisi teknis proyek BlockDev.

- **App Router**: Pola arsitektur routing pada Next.js berbasis folder `app/`.
- **Bento Grid**: Pola layout kartu modular asimetris untuk menampilkan fitur.
- **ScrollReveal**: Komponen animasi berbasis GSAP ScrollTrigger untuk teks bertahap.
- **ScrollStack**: Komponen tumpukan kartu interaktif dengan efek pinning saat scrolling.
- **Inter Display**: Varian tipografi Inter yang dioptimasi untuk ukuran tampilan/display besar melalui optical size axis (`opsz`).
