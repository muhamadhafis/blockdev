# Agent Workflow Instructions

## Alur Kerja Standar
1. Verifikasi branch kerja sebelum memulai modifikasi kode.
2. Pastikan dependensi dan tipe TypeScript valid.
3. Terapkan perubahan kode sesuai spesifikasi fungsional terkecil yang lengkap.
4. Jalankan formatter kode jika tersedia.
5. Jalankan validasi tipe dan pengujian otomatis.
6. Catat keputusan teknis di `docs/DECISION_LOG.md` dan perubahan di `CHANGELOG.md`.
7. Berhenti dan tanyakan konfirmasi kepada pengguna sebelum staging/commit.
